Event Guidelines

  1. Teams of 2 members each.
  2. Each team gets a starting clue on a chit, pointing to a computer or lab number.
  3. At that computer, fix the errors in the jumbled code and run the program successfully.
  4. The output gives you the next computer number. Repeat until you reach the final destination.
  5. Don't tamper with other computers, files or systems.
  6. Finish within the time limit. The team that reaches the final destination correctly in the shortest time wins, and the organizers' decision is final.

Solve the code → Get the number → Hunt the next computer

Objectives

  • To develop logical and analytical problem-solving skills.
  • To enhance programming and debugging proficiency.
  • To foster teamwork, collaboration, and ethical conduct.
  • To promote technical aptitude through experiential learning.

Event Outcomes

  • Engineering Knowledge: Apply programming concepts.
  • Problem Analysis: Identify and debug errors.
  • Engineering Tool Usage: Use computers and debugging tools effectively.
  • Teamwork: Collaborate to solve challenges.
